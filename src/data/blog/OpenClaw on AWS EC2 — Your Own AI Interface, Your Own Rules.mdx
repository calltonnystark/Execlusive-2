As AI continues to evolve, more developers and individuals are moving toward personal AI deployments — and for good reason. Commercial AI models, while powerful, often come with limitations that can slow down real work. From content restrictions to usage caps, these constraints can get in the way of productivity.

## Enter Open WebUI

**Open WebUI** is a self-hosted personal AI assistant designed to give you full control over your AI experience. Unlike commercial alternatives, it operates without the restrictions commonly found in mainstream platforms. It can integrate with your most-used tools and workflows, making it a flexible solution for both personal and professional use.

## What We’re Building Today

In this guide, we’ll take a different route — leveraging **AWS EC2** to deploy Open WebUI in the cloud. By the end, you’ll have a practical understanding of how Open WebUI works as a personal AI assistant and how to run it on your own EC2 instance.

## 1. Create a New EC2 Instance in AWS

For this project, we’re using **AWS EC2 (Elastic Compute Cloud)** as the hosting environment. EC2 is a good fit for this kind of deployment for two key reasons:

- **⚡ Cost-effective** — EC2 offers flexible pricing models, including pay-as-you-go options, so you only pay for what you use.
- **🚀 Better performance** — With a wide range of instance types available, EC2 gives you the compute power needed to run Open WebUI reliably in the cloud.

## 2. Launch a New EC2 Instance

The first step is to create and configure a new EC2 instance on AWS. Follow the steps below to get your server up and running.

![My old website](/blog/blog/2.webp)

### Instance Configuration

When setting up your new instance, use the following settings for optimal performance:

- **OS / AMI**: Ubuntu Server
- **Instance Type**: `t3.micro` / `t3.medium`
- **Key Pair**: `.pem` key for secure SSH access

> 💡 Tip: `t3.medium` is recommended if you plan to run heavier workloads. For basic testing, `t3.micro` is more affordable and usually sufficient.

## 3. Connect to Your EC2 Instance

Once your instance is running, AWS gives you two ways to connect to it remotely.

### i. Update the System

Before doing anything else, update and upgrade the system packages.

```bash
sudo apt update && sudo apt upgrade -y
```

![My old website](/blog/blog/3.webp)

### ii. SSH via Terminal

Use your `.pem` key file to securely connect through your terminal:

```bash
ssh -i "your-key.pem" ubuntu@your-ec2-public-ip
```

### iii. EC2 Instance Connect

This is a browser-based option available directly from the AWS Console. It works well for quick access without needing a terminal or key file.

## 4. Connect to the EC2 Instance via SSH

With the instance up and running, the next step is to establish a secure connection to your cloud server using **SSH (Secure Shell)**.

### Prerequisites

Before connecting, make sure you have the following ready:

- ✅ Your downloaded `.pem` key file
- ✅ The public IP address of your EC2 instance
- ✅ A terminal (Linux/macOS) or Git Bash / PuTTY (Windows)

### Step-by-Step Connection

1. Set the correct permissions on your `.pem` key:

```bash
chmod 400 your-key.pem
```

![My old website](/blog/blog/4.webp)

> 💡 Permission breakdown for `400`:
>
> - `4` = read (`r`)
> - `2` = write (`w`)
> - `1` = execute (`x`)
>
> The first digit is for the owner, the second for the group, and the third for others.

2. Connect to the server using the SSH command:

```bash
ssh -i "your-key.pem" ubuntu@your-ec2-public-ip
```

> 💡 Replace `your-key.pem` with your actual key filename and `your-ec2-public-ip` with your instance’s public IP from the AWS Console.

### Successful Connection

Once connected, you will see the **Ubuntu terminal prompt**, which confirms that you are securely logged into your cloud server and ready to continue.

## 5. Install OpenClaw Without Docker

Now it’s time to install OpenClaw. We’ll do it without Docker so the setup stays simple and easy to understand.

### Update your server packages

```bash
sudo apt update && sudo apt upgrade -y
```

### Run the install command

This command is intended for Linux distributions:

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```
